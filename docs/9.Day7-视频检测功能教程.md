## 需求分析

### 问题1：如何实现视频实时检测？

**为什么需要实时检测？**
传统的视频检测方式是先上传完整视频，然后后台处理完后再返回结果。这种方式有几个问题：

1. **用户等待时间长**：完整处理视频可能需要几分钟
2. **无法中途停止**：一旦开始处理就不能中断
3. **资源消耗大**：需要完整保存和处理整个视频
4. **交互体验差**：用户无法即时看到检测效果

**解决方案：**
实现视频播放时的实时检测功能，通过以下方式解决：

1. 视频播放时，周期性捕获视频帧
2. 将视频帧发送到后端进行实时检测
3. 使用Canvas在视频上叠加绘制检测框
4. 提供检测帧率控制，平衡性能和效果

### 问题2：检测框与视频目标不同步如何解决？

**核心问题原因：**

1. 之前使用 `video.videoWidth` 作为缩放基准，但视频实际显示尺寸（`clientWidth`）可能不同
2. Canvas 尺寸与视频显示尺寸不匹配
3. 检测间隔中检测框会消失，导致视觉闪烁

**优化方案：**

1. 使用视频显示尺寸（`clientWidth` / `clientHeight`）而不是原始视频尺寸
2. 动态调整 Canvas 尺寸以匹配视频显示尺寸
3. 使用 `requestAnimationFrame` 动画循环，在检测间隔保持上一帧的检测框显示
4. 实现插值渲染机制

## 后端实现

### 1. 数据模型定义

#### 问题：实时检测需要什么样的数据模型？

**为什么需要专用的实时检测模型？**

- 实时检测不需要保存完整历史记录到数据库
- 不需要保存原图和结果图到MinIO
- 需要快速返回检测结果，减少数据传输量
- 只需要检测框、目标数量等核心信息

**解决方案：**

```python
# backend/app/models/schemas.py
from pydantic import BaseModel
from typing import List, Optional
from datetime import datetime

class DetectionBox(BaseModel):
    """
    基础检测框数据模型

    为什么这样设计？
    - 包含坐标、置信度、类别信息
    - 作为基础模型被其他模型继承
    - 可复用在单图检测、批量检测中
    """
    x1: float                # 检测框左上角X坐标
    y1: float                # 检测框左上角Y坐标
    x2: float                # 检测框右下角X坐标
    y2: float                # 检测框右下角Y坐标
    confidence: float        # 置信度 (0-1)
    class_id: int           # 类别ID
    class_name: str         # 类别名称（英文）


class DetectionResult(BaseModel):
    """
    完整检测结果数据模型（用于单图/批量检测）

    为什么这样设计？
    - 包含数据库和存储相关字段
    - 返回检测结果图片URL
    - 包含创建时间用于历史记录
    """
    detection_id: str
    image_url: str
    result_image_url: str
    boxes: List[DetectionBox]
    total_objects: int
    detection_time: float
    model_name: str
    created_at: datetime


class RealtimeDetectionBox(DetectionBox):
    """
    实时检测框（继承基础检测框，添加中文名称）

    为什么单独设计？
    - 实时检测需要显示中文名称
    - 继承基础模型保持一致性
    - 中文名称可选，兼容不同场景
    """
    chinese_name: Optional[str] = None  # 类别名称（中文）


class RealtimeDetectionResult(BaseModel):
    """
    实时检测结果数据模型（轻量级，无存储字段）

    为什么这样设计？
    - 只包含检测框信息，减少数据传输
    - 不包含数据库相关字段（如id、创建时间）
    - 专门用于实时帧检测返回
    - 包含图像尺寸信息，便于前端对齐绘制
    """
    boxes: List[RealtimeDetectionBox]  # 检测框列表（含中文名称）
    total_objects: int                 # 检测到的目标总数
    detection_time: float              # 检测耗时（秒）
    image_width: int                   # 图片宽度
    image_height: int                  # 图片高度


class RealtimeDetectionResponse(BaseModel):
    """
    实时检测响应模型

    为什么单独创建这个模型？
    - 明确表示这是实时检测的响应
    - 未来可以扩展实时检测特有的字段
    - 与完整检测响应保持区分
    """
    success: bool
    message: str
    data: Optional[RealtimeDetectionResult] = None


class VideoDetectionResponse(BaseModel):
    """
    视频检测响应模型（用于完整视频检测）
    """
    success: bool
    message: str
    data: Optional[dict] = None
```

### 2. 实时检测服务实现

#### 问题：如何在检测服务中支持实时帧检测？

**为什么需要专门的实时检测方法？**

- 实时检测不需要保存结果
- 实时检测需要更快的响应速度
- 实时检测接收的是numpy数组而不是文件

**解决方案：**

```python
# backend/app/services/detection_service.py
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).parent.parent.parent))

import os
import time
import uuid
from datetime import datetime
from typing import List
from ultralytics import YOLO
import cv2

from app.config import settings
from app.models.schemas import DetectionBox, DetectionResult, RealtimeDetectionBox, RealtimeDetectionResult
from app.utils.file_utils import get_file_url
from app.utils.paths import Paths
from app.utils.logging_utils import setup_detection_logging

# 配置日志
logger = setup_detection_logging()


class DetectionService:
    def __init__(self):
        """
        初始化检测服务

        为什么这样初始化？
        - 启动时立即加载模型，避免首次检测延迟
        - 使用单例模式，确保模型只加载一次
        - 自动定位模型文件位置
        """
        self.model = None
        self.class_names = {}

        # 确保结果目录存在
        result_dir = Path(settings.RESULT_DIR)
        Paths.ensure_dir(result_dir)

        # 加载模型和初始化类别名称
        self._load_model()
        self._init_class_names()
        logger.info("✅ 检测服务初始化完成")

    def _load_model(self):
        """
        加载YOLO模型

        为什么这样设计？
        - 自动定位到backend根目录
        - 支持从本地文件加载模型
        - 提供清晰的日志输出
        """
        backend_dir = Path(__file__).parent.parent.parent  # backend/
        model_path = backend_dir / "yolo11n.pt"

        logger.info(f"正在加载模型：{model_path}")

        if os.path.exists(model_path):
            self.model = YOLO(model_path)
            logger.info(f"✅ 模型加载成功")
        else:
            logger.error(f"❌ 模型文件不存在：{model_path}")
            raise FileNotFoundError(f"Model file not found: {model_path}")

    def _init_class_names(self):
        """
        初始化类别名称映射

        为什么这样设计？
        - 使用COCO数据集类别（yolo11n默认）
        - 支持中英文对照
        """
        self.class_names = {
            0: "person",     # 人
            1: "bicycle",    # 自行车
            2: "car",        # 汽车
            3: "motorcycle", # 摩托车
            4: "airplane",   # 飞机
            5: "bus",        # 公交车
        }

    def get_class_chinese_name(self, class_name: str) -> str:
        """
        获取类别的中文名称

        参数:
            class_name: 类别英文名称

        返回:
            str: 类别中文名称
        """
        chinese_names = {
            'person': '人',
            'bicycle': '自行车',
            'car': '汽车',
            'motorcycle': '摩托车',
            'airplane': '飞机',
            'bus': '公交车',
        }
        return chinese_names.get(class_name, class_name)

    def detect_single_image(self, image_path: str, model_name: str = "pest-v1") -> DetectionResult:
        """
        单图检测（保存结果到数据库和存储）

        参数:
            image_path: 图片文件路径
            model_name: 模型名称

        返回:
            DetectionResult: 检测结果对象
        """
        start_time = time.time()
        detection_id = str(uuid.uuid4())
        logger.info(f"开始检测：{os.path.basename(image_path)}")

        try:
            results = self.model.predict(
                source=image_path,
                conf=settings.CONFIDENCE_THRESHOLD,
                iou=settings.IOU_THRESHOLD,
                save=False
            )

            boxes = []
            for result in results:
                for box in result.boxes:
                    x1, y1, x2, y2 = box.xyxy[0].tolist()
                    confidence = float(box.conf[0])
                    class_id = int(box.cls[0])
                    class_name = self.class_names.get(class_id, f"class_{class_id}")

                    boxes.append(DetectionBox(
                        x1=x1, y1=y1, x2=x2, y2=y2,
                        confidence=confidence,
                        class_id=class_id, class_name=class_name
                    ))

            # 保存检测结果图片
            result_filename = f"result_{uuid.uuid4().hex}.jpg"
            result_path = os.path.join(settings.RESULT_DIR, result_filename)
            annotated_image = results[0].plot()
            cv2.imwrite(result_path, cv2.cvtColor(annotated_image, cv2.COLOR_RGB2BGR))

            detection_time = time.time() - start_time
            image_filename = os.path.basename(image_path)

            logger.info(f"检测完成 | 耗时：{detection_time:.3f}s | 目标数：{len(boxes)}")

            return DetectionResult(
                detection_id=detection_id,
                image_url=get_file_url(image_filename, "static/uploads"),
                result_image_url=get_file_url(result_filename, "static/results"),
                boxes=boxes,
                total_objects=len(boxes),
                detection_time=round(detection_time, 3),
                model_name=model_name,
                created_at=datetime.now()
            )

        except Exception as e:
            logger.error(f"检测失败：{str(e)}", exc_info=True)
            raise

    def detect_frame_realtime(self, image, confidence_threshold: float = 0.25,
                              iou_threshold: float = 0.7):
        """
        实时视频帧检测（不保存到数据库，直接返回结果）

        为什么使用numpy数组而不是文件？
        - 视频帧本来就是numpy数组格式
        - 避免文件IO开销，提高速度
        - 减少内存拷贝

        参数:
            image: numpy数组格式的图片（OpenCV格式）
            confidence_threshold: 置信度阈值
            iou_threshold: IOU阈值

        返回:
            RealtimeDetectionResult: 检测结果对象
        """
        if self.model is None:
            raise RuntimeError("模型未加载")

        start_time = time.time()

        # 调用YOLO模型进行预测
        results = self.model.predict(
            source=image,
            conf=confidence_threshold,
            iou=iou_threshold,
            save=False  # 不保存结果图
        )

        # 解析检测结果
        boxes = []
        for result in results:
            for box in result.boxes:
                # 获取框坐标 (xyxy格式)
                x1, y1, x2, y2 = box.xyxy[0].tolist()

                # 获取置信度和类别
                confidence = float(box.conf[0])
                class_id = int(box.cls[0])
                class_name = self.class_names.get(class_id, f"class_{class_id}")

                # 创建DetectionBox对象
                boxes.append(DetectionBox(
                    x1=round(x1, 2),
                    y1=round(y1, 2),
                    x2=round(x2, 2),
                    y2=round(y2, 2),
                    confidence=round(confidence, 4),
                    class_id=class_id,
                    class_name=class_name,
                    chinese_name=self.get_class_chinese_name(class_name)
                ))

        # 计算检测耗时
        detection_time = time.time() - start_time

        # 返回实时检测结果
        # 为什么不保存到数据库和MinIO？
        # - 实时检测不需要持久化
        # - 减少后端压力
        # - 前端只需要检测框信息
        return RealtimeDetectionResult(
            total_objects=len(boxes),
            boxes=boxes,
            detection_time=round(detection_time, 4),
            image_width=image.shape[1] if len(image.shape) >= 2 else 0,
            image_height=image.shape[0] if len(image.shape) >= 2 else 0
        )


# 全局单例
detection_service = DetectionService()
```

### 3. 实时检测API接口（video_detection.py）

#### 问题：如何设计实时检测的API接口？

**为什么需要专门的视频检测接口文件？**

- 将所有视频相关功能集中管理
- 便于维护和扩展
- 清晰的代码组织结构

**解决方案：**

```python
# backend/app/api/video_detection.py
import cv2
import numpy as np
from fastapi import APIRouter, UploadFile, File, Form, HTTPException

from app.services.detection_service import detection_service
from app.utils.file_utils import ensure_directories
from app.utils.logging_utils import setup_detection_logging
from app.models.schemas import RealtimeDetectionResponse

# 配置日志
logger = setup_detection_logging()

# 创建路由
router = APIRouter(prefix="/video-detection", tags=["video-detection"])

# 确保目录存在（复用现有工具）
ensure_directories()


# =============================================================================
# 实时视频帧检测接口
# =============================================================================

@router.post("/realtime-frame", response_model=RealtimeDetectionResponse)
async def detect_realtime_frame(
    file: UploadFile = File(...),
    confidence_threshold: float = Form(0.25, description="置信度阈值"),
    iou_threshold: float = Form(0.7, description="IOU阈值")
):
    """
    实时视频帧检测接口（接收单帧图片，返回检测结果）

    功能：
    - 接收视频播放时的单帧图片
    - 使用YOLO模型进行目标检测
    - 返回检测结果（不保存到数据库）

    参数：
        file: 视频帧图片文件
        confidence_threshold: 置信度阈值
        iou_threshold: IOU阈值

    返回：
        RealtimeDetectionResponse: 检测结果
    """
    try:
        # 读取上传的帧数据
        contents = await file.read()
        nparr = np.frombuffer(contents, np.uint8)
        image = cv2.imdecode(nparr, cv2.IMREAD_COLOR)

        if image is None:
            raise HTTPException(status_code=400, detail="无法解析图片")

        # 调用实时检测方法
        result = detection_service.detect_frame_realtime(
            image=image,
            confidence_threshold=confidence_threshold,
            iou_threshold=iou_threshold
        )

        # 返回响应
        return RealtimeDetectionResponse(
            success=True,
            message="检测成功",
            data=result
        )

    except HTTPException:
        raise
    except Exception as e:
        logger.error(f"实时帧检测错误: {str(e)}", exc_info=True)
        raise HTTPException(
            status_code=500,
            detail=f"实时帧检测失败: {str(e)}"
        )

@router.post("/upload", response_model=VideoDetectionResponse)
async def upload_video_and_detect(

    """
    完整视频检测接口（上传视频文件，处理整个视频并返回结果）
    
    功能：
    - 接收完整视频文件
    - 按指定间隔抽取帧进行检测
    - 返回完整的检测结果（包含所有帧的检测数据）
    
    参数：
        file: 视频文件
        model_name: 模型名称
        frame_interval: 帧间隔（每隔多少帧检测一次）
        confidence_threshold: 置信度阈值
        iou_threshold: IOU阈值
    
    返回：
        VideoDetectionResponse: 视频检测结果
    """
    try:
        # 生成检测ID
        detection_id = str(uuid.uuid4())
        
        # 确保上传目录存在
        upload_dir = Path(settings.UPLOAD_DIR)
        upload_dir.mkdir(parents=True, exist_ok=True)
        
        # 保存上传的视频文件
        video_filename = f"video_{uuid.uuid4().hex}.mp4"
        video_path = upload_dir / video_filename
        
        with open(video_path, "wb") as buffer:
            buffer.write(await file.read())
        
        logger.info(f"视频文件已保存: {video_path}")
        
        # 处理视频
        result = process_video_detection(
            video_path=str(video_path),
            detection_id=detection_id,
            model_name=model_name,
            frame_interval=frame_interval,
            confidence_threshold=confidence_threshold,
            iou_threshold=iou_threshold
        )
        
        # 删除临时视频文件
        os.remove(video_path)
        
        return VideoDetectionResponse(
            success=True,
            message="视频检测完成",
            data=result
        )
    
    except HTTPException:
        raise
    except Exception as e:
        logger.error(f"视频检测错误: {str(e)}", exc_info=True)
        raise HTTPException(
            status_code=500,
            detail=f"视频检测失败: {str(e)}"
        )


def process_video_detection(
    video_path: str,
    detection_id: str,
    model_name: str = "rsod-yolo11n",
    frame_interval: int = 10,
    confidence_threshold: float = 0.25,
    iou_threshold: float = 0.7
):
    """
    处理完整视频检测（核心处理函数）
    
    参数:
        video_path: 视频文件路径
        detection_id: 检测ID
        model_name: 模型名称
        frame_interval: 帧间隔
        confidence_threshold: 置信度阈值
        iou_threshold: IOU阈值
    
    返回:
        dict: 检测结果字典
    """
    import time
    start_time = time.time()
    logger.info(f"开始处理视频检测: {video_path}")
    
    # 打开视频文件
    cap = cv2.VideoCapture(video_path)
    
    if not cap.isOpened():
        raise RuntimeError("无法打开视频文件")
    
    # 获取视频信息
    frame_count = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    fps = cap.get(cv2.CAP_PROP_FPS)
    width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
    height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
    
    logger.info(f"视频信息: 帧数={frame_count}, FPS={fps}, 分辨率={width}x{height}")
    
    # 存储检测结果
    all_detections = []
    total_objects = 0
    processed_frames = 0
    
    # 逐帧处理
    while cap.isOpened():
        ret, frame = cap.read()
        
        if not ret:
            break
        
        # 只处理指定间隔的帧
        current_frame = int(cap.get(cv2.CAP_PROP_POS_FRAMES))
        if current_frame % frame_interval != 0:
            continue
        
        try:
            # 调用检测服务
            result = detection_service.detect_frame_realtime(
                image=frame,
                confidence_threshold=confidence_threshold,
                iou_threshold=iou_threshold
            )
            
            # 记录检测结果
            frame_result = {
                "frame_index": current_frame,
                "time_ms": (current_frame / fps) * 1000,
                "detection": result.dict()
            }
            all_detections.append(frame_result)
            
            total_objects += result.total_objects
            processed_frames += 1
            
            # 记录进度
            if processed_frames % 10 == 0:
                progress = (current_frame / frame_count) * 100
                logger.info(f"检测进度: {progress:.1f}%")
        
        except Exception as e:
            logger.warning(f"处理帧 {current_frame} 时出错: {str(e)}")
            continue
    
    # 释放资源
    cap.release()
    
    # 构建返回结果
    result_data = {
        "detection_id": detection_id,
        "total_objects": total_objects,
        "detection_time": round(time.time() - start_time, 2),
        "width": width,
        "height": height,
        "model_name": model_name,
        "result_video_url": None,  # 当前不生成结果视频
        "video_info": {
            "frame_count": frame_count,
            "fps": fps,
            "width": width,
            "height": height
        },
        "parameters": {
            "model_name": model_name,
            "frame_interval": frame_interval,
            "confidence_threshold": confidence_threshold,
            "iou_threshold": iou_threshold
        },
        "summary": {
            "total_frames_processed": processed_frames,
            "total_objects_detected": total_objects,
            "detection_time": datetime.now().isoformat()
        },
        "frames": all_detections
    }
    
    # 保存结果JSON文件
    result_dir = Path(settings.RESULT_DIR)
    result_dir.mkdir(parents=True, exist_ok=True)
    result_filename = f"video_result_{detection_id}.json"
    result_path = result_dir / result_filename
    
    import json
    with open(result_path, "w", encoding="utf-8") as f:
        json.dump(result_data, f, ensure_ascii=False, indent=2)
    
    logger.info(f"视频检测完成: 处理帧={processed_frames}, 检测目标数={total_objects}")
    
    return result_data
```

<script setup>
import { ref, computed, watch, onUnmounted, nextTick } from "vue";
import { ElMessage } from "element-plus";
import {
  Monitor,
  Upload,
  Check,
  List,
  CircleCheck,
  Refresh,
  VideoPause,
} from "@element-plus/icons-vue";
import { detectVideo, detectRealtimeFrame } from "../api/detection";

// 视频相关状态
const videoRef = ref(null);
const canvasRef = ref(null);
const hasVideo = ref(false);
const originalVideoUrl = ref(null);
const videoDuration = ref(0);
const currentTime = ref(0);
const currentFrameIndex = ref(0);

// 检测相关状态
const isDetecting = ref(false);
const detectionResult = ref(null);
const currentDetection = ref(null);
const detectionMode = ref("realtime"); // 'realtime' 或 'full'

// 检测参数
const confidenceThreshold = ref(0.25);
const iouThreshold = ref(0.7);
const frameInterval = ref(1);
const detectionFPS = ref(5); // 实时检测的帧率

// 计算属性
const realtimeMode = computed(() => detectionMode.value === "realtime");
const hasDetectionResult = computed(() => detectionResult.value !== null);

// 定时器和动画帧
let detectionTimer = null;
let canvasContext = null;
let animationFrameId = null;

// 保存上一帧检测结果，用于插值显示
let lastBoxes = [];
let lastVideoWidth = 0;
let lastVideoHeight = 0;
let isProcessingFrame = false; // 防止同时处理多帧

// 辅助函数
const formatDuration = (seconds) => {
  if (!seconds || seconds <= 0) return "--:--";
  const mins = Math.floor(seconds / 60);
  const secs = Math.floor(seconds % 60);
  return `${mins.toString().padStart(2, "0")}:${secs.toString().padStart(2, "0")}`;
};

const getTagType = () => {
  if (isDetecting.value) return "success";
  if (currentDetection.value) return "info";
  return "info";
};

const getTagText = () => {
  if (isDetecting.value) return "实时检测中";
  if (currentDetection.value) return "实时检测已结束";
  return "等待检测";
};

// 视频上传
const triggerFileInput = () => {
  const input = document.querySelector(".video-file-input");
  if (input) {
    input.click();
  }
};

const handleVideoUpload = async (event) => {
  const file = event.target.files?.[0];
  if (!file) return;

  try {
    // 清理之前的URL，防止内存泄漏
    if (originalVideoUrl.value) {
      URL.revokeObjectURL(originalVideoUrl.value);
    }

    originalVideoUrl.value = URL.createObjectURL(file);
    hasVideo.value = true;
    detectionResult.value = null;
    currentDetection.value = null;
    currentFrameIndex.value = 0;
    currentTime.value = 0;

    // 等待视频元素挂载
    await nextTick();

    const video = videoRef.value;
    if (video) {
      // 监听视频元数据加载
      video.onloadedmetadata = () => {
        videoDuration.value = video.duration;
      };

      // 监听视频加载错误
      video.onerror = () => {
        console.error("视频加载错误");
        ElMessage.error("视频加载失败");
        hasVideo.value = false;
      };
    }
  } catch (error) {
    console.error("视频加载失败:", error);
    ElMessage.error("视频加载失败");
  }
};

// 视频事件处理
const onVideoLoaded = () => {
  const video = videoRef.value;
  if (video) {
    videoDuration.value = video.duration;

    // 初始化Canvas
    nextTick(() => {
      initCanvas();
    });
  }
};

const onTimeUpdate = () => {
  const video = videoRef.value;
  if (video) {
    currentTime.value = video.currentTime;
  }
};

const onVideoEnded = () => {
  if (realtimeMode.value && isDetecting.value) {
    stopRealtimeDetection();
    ElMessage.success("视频播放完成，检测结束");
  }
};

// Canvas相关（优化版）
const initCanvas = () => {
  const video = videoRef.value;
  const canvas = canvasRef.value;

  if (!video || !canvas) return;

  // 设置Canvas尺寸与视频显示尺寸一致，确保坐标对齐
  const displayWidth = video.clientWidth || video.offsetWidth;
  const displayHeight = video.clientHeight || video.offsetHeight;
  canvas.width = displayWidth;
  canvas.height = displayHeight;

  // 获取Canvas 2D上下文
  canvasContext = canvas.getContext("2d");

  // 清空Canvas
  canvasContext.clearRect(0, 0, canvas.width, canvas.height);
};

const clearCanvas = () => {
  if (!canvasContext || !canvasRef.value) return;
  canvasContext.clearRect(0, 0, canvasRef.value.width, canvasRef.value.height);
};

const drawDetectionBoxes = (
  boxes,
  videoWidth,
  videoHeight,
  interpolate = false,
) => {
  if (!canvasContext || !canvasRef.value || !videoRef.value) return;

  const canvas = canvasRef.value;
  const video = videoRef.value;

  // 确保Canvas尺寸与视频显示尺寸一致（动态调整）
  const displayWidth = video.clientWidth || video.offsetWidth;
  const displayHeight = video.clientHeight || video.offsetHeight;

  if (canvas.width !== displayWidth || canvas.height !== displayHeight) {
    canvas.width = displayWidth;
    canvas.height = displayHeight;
  }

  // 计算缩放比例：视频原始尺寸 -> 显示尺寸
  const scaleX = displayWidth / videoWidth;
  const scaleY = displayHeight / videoHeight;

  // 清空画布
  canvasContext.clearRect(0, 0, displayWidth, displayHeight);

  // 如果需要插值且有上一帧数据，使用上一帧数据保持显示
  let boxesToDraw = boxes;
  if (interpolate && lastBoxes.length > 0) {
    boxesToDraw = lastBoxes;
    videoWidth = lastVideoWidth;
    videoHeight = lastVideoHeight;
  }

  // 颜色映射
  const colorMap = {
    aircraft: "#FF6B6B",
    oiltank: "#4ECDC4",
    overpass: "#45B7D1",
    playground: "#96CEB4",
  };

  // 绘制每个检测框
  boxesToDraw.forEach((box) => {
    const x1 = box.x1 * scaleX;
    const y1 = box.y1 * scaleY;
    const x2 = box.x2 * scaleX;
    const y2 = box.y2 * scaleY;
    const color = colorMap[box.class_name] || "#FF6B6B";

    // 绘制边框
    canvasContext.strokeStyle = color;
    canvasContext.lineWidth = 2;
    canvasContext.strokeRect(x1, y1, x2 - x1, y2 - y1);

    // 绘制标签背景
    canvasContext.fillStyle = color;
    const label = `${box.chinese_name || box.class_name} ${(box.confidence * 100).toFixed(0)}%`;
    const labelWidth = canvasContext.measureText(label).width + 10;
    canvasContext.fillRect(x1, y1 - 20, labelWidth, 20);

    // 绘制标签文字
    canvasContext.fillStyle = "#FFFFFF";
    canvasContext.font = "14px Arial";
    canvasContext.fillText(label, x1 + 5, y1 - 5);
  });

  // 保存当前帧数据（只有真实检测时才更新）
  if (!interpolate) {
    lastBoxes = boxes;
    lastVideoWidth = videoWidth;
    lastVideoHeight = videoHeight;
  }
};

// 实时检测核心逻辑（优化版）
const captureAndDetectFrame = async () => {
  const video = videoRef.value;
  if (!video || video.paused || video.ended || isProcessingFrame) return;

  isProcessingFrame = true;

  try {
    // 创建临时Canvas捕获当前帧 - 保持原图尺寸，确保坐标准确
    const tempCanvas = document.createElement("canvas");
    tempCanvas.width = video.videoWidth;
    tempCanvas.height = video.videoHeight;
    const ctx = tempCanvas.getContext("2d");
    ctx.drawImage(video, 0, 0);

    // 转换为Blob - 适度压缩以平衡质量和速度
    const blob = await new Promise((resolve) => {
      tempCanvas.toBlob((b) => resolve(b), "image/jpeg", 0.6);
    });

    if (!blob) {
      isProcessingFrame = false;
      return;
    }

    // 发送到后端检测
    const formData = new FormData();
    formData.append("file", blob, "frame.jpg");
    formData.append(
      "confidence_threshold",
      confidenceThreshold.value.toString(),
    );
    formData.append("iou_threshold", iouThreshold.value.toString());

    const response = await detectRealtimeFrame(formData);

    if (response.success && response.data) {
      currentDetection.value = response.data;

      // 直接使用后端返回的检测框，不需要缩放（因为我们保持了原图尺寸）
      const boxes = response.data.boxes || [];

      // 在Canvas上绘制检测框
      drawDetectionBoxes(
        boxes,
        response.data.image_width,
        response.data.image_height,
      );

      // 更新帧计数
      currentFrameIndex.value++;
    }
  } catch (error) {
    console.error("帧检测失败:", error);
  } finally {
    isProcessingFrame = false;
  }
};

const animateCanvas = () => {
  if (!isDetecting.value) return;

  const video = videoRef.value;
  // 在动画帧中持续绘制上一帧的检测结果，保持视觉流畅
  if (
    video &&
    !video.paused &&
    !video.ended &&
    lastBoxes.length > 0 &&
    lastVideoWidth > 0
  ) {
    drawDetectionBoxes([], lastVideoWidth, lastVideoHeight, true);
  }

  // 继续下一帧动画
  animationFrameId = requestAnimationFrame(animateCanvas);
};

const startRealtimeDetection = async () => {
  const video = videoRef.value;
  if (!video) {
    ElMessage.error("视频未加载");
    return;
  }

  // 确保视频已加载
  if (video.readyState < 2) {
    ElMessage.info("正在加载视频，请稍候...");
    await new Promise((resolve) => {
      video.onloadeddata = resolve;
      video.onerror = () => {
        ElMessage.error("视频加载失败");
        resolve();
      };
      // 超时处理
      setTimeout(resolve, 10000);
    });
  }

  if (video.readyState < 2) {
    ElMessage.error("视频加载失败");
    return;
  }

  isDetecting.value = true;
  currentDetection.value = null;
  currentFrameIndex.value = 0;
  lastBoxes = []; // 重置上一帧数据
  isProcessingFrame = false;

  // 初始化Canvas
  nextTick(() => {
    initCanvas();
    clearCanvas();
  });

  // 延迟一点再开始播放，确保Canvas已初始化
  await nextTick();

  // 自动播放视频
  try {
    await video.play();
    ElMessage.success("开始实时检测");
  } catch (err) {
    console.error("播放失败:", err);
    ElMessage.warning("自动播放被阻止，请手动点击播放");
  }

  // 启动动画循环，保持检测框持续显示
  animateCanvas();

  // 设置定时器定期捕获帧
  const intervalMs = Math.floor(1000 / detectionFPS.value);
  detectionTimer = setInterval(captureAndDetectFrame, intervalMs);
};

const stopRealtimeDetection = () => {
  const video = videoRef.value;

  // 停止定时器
  if (detectionTimer) {
    clearInterval(detectionTimer);
    detectionTimer = null;
  }

  // 停止动画循环
  if (animationFrameId) {
    cancelAnimationFrame(animationFrameId);
    animationFrameId = null;
  }

  // 暂停视频
  if (video) {
    video.pause();
  }

  isDetecting.value = false;

  // 清空Canvas和数据
  clearCanvas();
  lastBoxes = [];
  isProcessingFrame = false;
};

const performVideoDetection = async () => {
  if (!originalVideoUrl.value) {
    ElMessage.warning("请先上传视频");
    return;
  }

  // 实时检测模式
  if (realtimeMode.value) {
    startRealtimeDetection();
    return;
  }

  // 完整检测模式
  try {
    isDetecting.value = true;

    const videoFile = await fetch(originalVideoUrl.value).then((res) =>
      res.blob(),
    );

    const formData = new FormData();
    formData.append("file", videoFile, "video.mp4");
    formData.append("model_name", "rsod-yolo11n");
    formData.append("frame_interval", frameInterval.value.toString());
    formData.append(
      "confidence_threshold",
      confidenceThreshold.value.toString(),
    );
    formData.append("iou_threshold", iouThreshold.value.toString());

    const response = await detectVideo(formData);

    if (response.success && response.data) {
      detectionResult.value = response.data;
      ElMessage.success("视频检测成功！");
    } else {
      ElMessage.error(response.message || "检测失败");
    }
  } catch (error) {
    console.error("视频检测错误:", error);
    ElMessage.error("检测失败，请稍后重试");
  } finally {
    isDetecting.value = false;
  }
};

// 监听检测模式变化
watch(detectionMode, (newMode) => {
  if (newMode === "realtime" && isDetecting.value) {
    // 从完整检测切换到实时检测
    stopRealtimeDetection();
  }
});

// 组件卸载时清理
onUnmounted(() => {
  stopRealtimeDetection();
  if (originalVideoUrl.value) {
    URL.revokeObjectURL(originalVideoUrl.value);
  }
});
</script>

### 2. 检测框同步优化方案

**问题原因：**
- 之前使用 `video.videoWidth`（原始视频分辨率）作为缩放基准
- 但视频在页面中的实际显示尺寸（`clientWidth`）通常不同
- Canvas尺寸没有动态调整，导致坐标计算错误
- 检测间隔中检测框会消失，用户体验差

**优化点：**
1. **使用显示尺寸：** 使用 `video.clientWidth/clientHeight` 获取实际显示尺寸
2. **动态Canvas尺寸：** 在 `drawDetectionBoxes` 中动态调整Canvas尺寸
3. **插值渲染机制：** 保存上一帧检测结果，在检测间隔持续显示
4. **requestAnimationFrame：** 使用浏览器动画帧循环，确保渲染流畅

**关键代码：**
```javascript
const drawDetectionBoxes = (boxes, videoWidth, videoHeight, interpolate = false) => {
  // 1. 获取视频显示尺寸（不是原始尺寸）
  const displayWidth = video.clientWidth || video.offsetWidth;
  const displayHeight = video.clientHeight || video.offsetHeight;

  // 2. 动态调整Canvas尺寸
  if (canvas.width !== displayWidth || canvas.height !== displayHeight) {
    canvas.width = displayWidth;
    canvas.height = displayHeight;
  }

  // 3. 计算正确的缩放比例：后端返回坐标 -> 显示尺寸
  const scaleX = displayWidth / videoWidth;
  const scaleY = displayHeight / videoHeight;

  // 4. 插值显示：在检测间隔使用上一帧数据
  if (interpolate && lastBoxes.length > 0) {
    boxesToDraw = lastBoxes;
    videoWidth = lastVideoWidth;
    videoHeight = lastVideoHeight;
  }

  // 5. 绘制检测框
  // ...
};
````

### 3. 检测帧率控制

**目的：**

- 避免后端过载
- 减少网络流量
- 根据设备性能调整
- 平衡检测精度和延迟

**实现方式：**

```javascript
// 用户可配置：2-15 fps
const detectionFPS = ref(5);

// 计算检测间隔（毫秒）
const intervalMs = Math.floor(1000 / detectionFPS.value);

// 设置定时器
detectionTimer = setInterval(captureAndDetectFrame, intervalMs);
```

**最佳实践建议：**

- 普通设备：3-5 fps
- 高性能设备：8-12 fps
- 需要减少延迟：降低到2-3 fps（检测间隔更大，但视觉更流畅）

### 4. 图像压缩优化

**压缩策略：**

- 格式：JPEG（兼顾质量和压缩率）
- 质量：0.6（平衡检测精度和传输速度）
- 保持原始分辨率：确保检测坐标准确

**代码实现：**

const blob = await new Promise((resolve) => {

## 使用说明

### 实时检测模式

1. **上传视频**
   - 点击视频占位区域
   - 选择本地视频文件（支持mp4、avi、mov等格式）
   - 视频会自动加载并预览

2. **调整参数**
   - **置信度阈值：** 控制检测灵敏度（0.01-0.9）
     - 更低：检测更多目标，但可能有假阳性
     - 更高：更准确，但可能漏检
   - **检测帧率：** 设置检测频率（2-15 fps）
     - 更高：检测更频繁，但延迟可能增加
     - 更低：减少延迟，视觉更流畅

3. **开始检测**
   - 点击「开始检测」按钮
   - 视频会自动播放
   - 检测框会实时叠加在视频上
   - 实时统计信息显示当前帧数、目标数量、检测耗时

4. **查看结果**
   - 实时检测结果显示在右侧面板
   - 包括检测到的目标类别和置信度
   - 如果没有检测到目标会显示提示信息

5. **停止检测**
   - 点击「停止检测」按钮
   - 视频会暂停
   - 检测框会清除

### 完整检测模式

1. **选择模式**
   - 在检测模式选择中选择「完整检测」

2. **调整参数**
   - 置信度阈值
   - 检测帧间隔：每隔多少帧检测一次（1-10）

3. **开始检测**
   - 点击「开始检测」
   - 视频会完整上传到后端处理
   - 处理完成后返回结果视频

4. **查看结果**
   - 检测结果显示目标总数、检测耗时
   - 可以播放结果视频查看带检测框的内容
   - 显示视频分辨率和使用的模型信息

### 常见问题

**Q: 检测框和视频目标不对齐怎么办？**
A: 确保使用最新版本代码，已优化坐标计算逻辑。如果仍有问题，尝试刷新页面重新上传视频。

**Q: 检测有延迟怎么办？**
A: 可以降低检测帧率（例如从5fps降到3fps），这样检测间隔更大，但视觉上会更流畅，同时检测框会持续显示。

**Q: 检测不到目标怎么办？**
A: 尝试降低置信度阈值，或确认视频内容包含可检测的目标类别（飞机、油罐、立交桥、操场）。

**Q: 视频无法播放怎么办？**
A: 检查视频格式是否为浏览器支持的格式（推荐mp4），并确保视频文件没有损坏。

**Q: 如何提高检测速度？**
A: 可以降低检测帧率，或者在网络状况好的情况下使用，图片压缩已优化为质量0.6平衡速度和精度。
